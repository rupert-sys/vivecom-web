# VIVEcom · Soluciones

Sitio estático (un solo `index.html` + `logo.png`, sin dependencias) de VIVEcom con su catálogo de ciberseguridad, nube y virtualización.

- Editar productos: arreglo `PRODUCTS` dentro de `index.html`.
- Editar soluciones por necesidad: arreglo `NEEDS`.
- Formulario: arma un correo a ventas@vivecom.mx con los productos elegidos.

## Publicar en GitHub Pages
Settings → Pages → Deploy from branch → `main` / root.
Para usar vivecom.mx: agrega un archivo `CNAME` con `www.vivecom.mx` y apunta el DNS (CNAME `www` → `rupert-sys.github.io`).
